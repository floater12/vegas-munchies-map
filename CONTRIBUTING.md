# Contributing a correction

If a price, hour, address, or other fact looks wrong, [report a change](https://github.com/floater12/vegas-munchies-map/issues/new?title=Correction:%20&body=Page:%20%0AWhat%20changed:%20%0ASource%20link%20(optional):%20).

Include the page, what changed, and a link to the current official source when you have one. Do not change prices, hours, addresses, license numbers, sources, or dates unless that official source was checked.
